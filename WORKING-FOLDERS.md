# Сначала выберите рабочую папку

> [!IMPORTANT]
> **Обязательно прочитайте перед запуском Launcher и подключением к Notion.** Укажите свою папку для Filesystem и свой проект для Rojo. Launcher использует локальные настройки установленных MCP-серверов; автоматического окна выбора папки нет.

Свою папку можно задать сразу при настройке. Позже её тоже можно сменить: сохраните новое значение и примените его по инструкции ниже. Уже работающий сервер не переключается от одного редактирования JSON.

## Папка установки и рабочая папка

Сначала создайте карту `.runtime/servers.json` по [README](README.md#configure-this-pc). Все команды ниже выполняются в PowerShell из корня репозитория.

| Настройка | Что указать |
| --- | --- |
| `projectDirectory` в `.runtime/servers.json` | Папку установки соответствующего MCP, где лежат `start.ps1`, `stop.ps1` и его `.runtime/`. |
| `allowedDirectory` в конфиге Filesystem | Существующую папку, в которой клиент сможет читать, создавать и редактировать файлы. |
| `projectRoot` в конфиге Rojo или ARC-профиле | Существующую папку проекта с `default.project.json`. |

Для совместной работы с одним Roblox-проектом папка Rojo должна находиться внутри разрешённой папки Filesystem или совпадать с ней. Например, Filesystem может видеть `D:\Projects\MyGame`, а Rojo собирать этот же проект. Изменение одного подключения не меняет настройки другого.

В JSON обратный слеш нужно удваивать: путь `D:\Projects\MyGame` записывается как `"D:\\Projects\\MyGame"`. Сохраняйте обычный JSON без комментариев в UTF-8 без BOM. Примеры путей замените своими.

## Filesystem: выбрать или сменить папку

Если MCP ещё не настроен и его `.runtime/config.json` отсутствует, сначала выполните первоначальную настройку по инструкции установленного сервера. Она может создать конфиг с папкой по умолчанию. Затем остановите сервер, выберите свою папку по шагам ниже и только после проверки подключайте Notion. Этот репозиторий не устанавливает сервер и не создаёт его полный конфиг.

Если Filesystem уже работает, сначала штатно остановите его:

```powershell
.\MCP-Commands.ps1 Stop Filesystem
```

Дождитесь успешной остановки. Если команда сообщила об ошибке, сначала устраните её по [MCP-COMMANDS.md](MCP-COMMANDS.md).

Откройте конфиг именно установленного Filesystem из вашей карты:

```powershell
$servers = Get-Content -LiteralPath '.runtime\servers.json' -Raw | ConvertFrom-Json
$filesystem = $servers | Where-Object { $_.id -eq 'Filesystem' }
notepad (Join-Path $filesystem.projectDirectory '.runtime\config.json')
```

Измените только значение `allowedDirectory`, например:

```json
"allowedDirectory": "D:\\Projects\\MyGame"
```

Это пример одной строки внутри существующего конфига. Сохраните остальные поля, включая `token` и `port`. Выбранная папка должна существовать. Не выбирайте папку установки самого Filesystem, её подпапку или родительскую папку, содержащую эту установку: сервер отклоняет такие пути.

Запустите сервер и проверьте фактическую папку:

```powershell
.\MCP-Commands.ps1 Start Filesystem
.\MCP-Commands.ps1 Status Filesystem
```

В результате `Status` проверьте разрешённую папку. В Notion можно дополнительно попросить: «Вызови `list_allowed_directories` и покажи, где ты можешь работать». Все файлы внутри выбранной папки доступны этому файловому подключению.

## Rojo: выбрать или сменить проект

Папка должна уже содержать `default.project.json`. Если MCP ещё не настроен, сначала выполните первоначальную настройку установленного Rojo MCP, указав эту папку.

### Через ARC-профиль

При первом создании профиля выполните:

```powershell
Copy-Item arc-command-settings.example.json .runtime\arc-command-settings.json
notepad .runtime\arc-command-settings.json
```

Если профиль уже есть, откройте его в редакторе без повторного копирования шаблона. Задайте `projectRoot` — папку своего проекта, `rojoExecutable` — полный путь к своему `rojo.exe`. Настройте остальные поля для своего ПК по [ARC-COMMANDS.md](ARC-COMMANDS.md).

Сохраните профиль и примените выбор:

```powershell
.\Arc-Commands.ps1 Mcp
.\MCP-Commands.ps1 Status Rojo
```

`Mcp` сохраняет резервную копию конфига, при смене проекта штатно останавливает работающий Rojo MCP и запускает его с выбранными путями. Он сохраняет существующий ключ. Для следующей смены папки достаточно снова отредактировать профиль и выполнить эти две команды.

При наличии профиля `MCP-Commands.ps1 Start Rojo`, `Restart Rojo` и `Start All` применяют его автоматически с основной картой серверов. Прямой `Start-All.cmd` профиль не применяет; используйте `MCP-Commands.ps1 Start All`. Ручное изменение только конфига Rojo будет заменено значениями профиля при следующем таком запуске.

### Без ARC-профиля

Штатно остановите Rojo MCP:

```powershell
.\MCP-Commands.ps1 Stop Rojo
```

После успешной остановки откройте его конфиг:

```powershell
$servers = Get-Content -LiteralPath '.runtime\servers.json' -Raw | ConvertFrom-Json
$rojo = $servers | Where-Object { $_.id -eq 'Rojo' }
notepad (Join-Path $rojo.projectDirectory '.runtime\config.json')
```

Измените `projectRoot` на свою папку. При необходимости измените `rojoExecutable`. Сохраните остальные поля, особенно `token`, `port` и `servePort`. Если в среде запуска заданы `ROJO_PROJECT_ROOT` или `ROJO_EXECUTABLE`, их значения имеют приоритет: приведите их в соответствие с новым выбором или уберите собственные переопределения.

```powershell
.\MCP-Commands.ps1 Start Rojo
.\MCP-Commands.ps1 Status Rojo
```

Проверьте строку `Project` в результате. Запуск MCP сам по себе не включает синхронизацию. Для неё вызовите `rojo_serve` в Notion. Перед подключением Rojo-плагина к полученному локальному адресу проверьте выбранный проект и нужный Place: синхронизация переносит файлы проекта в открытый Place.

## После смены папки

Получите текущую ссылку изменённого подключения:

```powershell
.\MCP-Commands.ps1 Links Filesystem
.\MCP-Commands.ps1 Links Rojo
```

Выполните нужную строку. Если запущены все четыре сервера, можно получить все ссылки командой `.\MCP-Commands.ps1 Links All`.

Если HTTPS-домен изменился, обновите URL соответствующего MCP в Notion. При сохранении поля `token` используется прежний Bearer-токен. Попросите Notion повторно проверить разрешённую папку и `rojo_status` перед редактированием или сборкой нового проекта.

Выбор папки Filesystem ограничивает только Filesystem. Для Blender откройте нужный `.blend`, для Roblox Studio — нужный Place. У отдельно установленного CMD / PC Control MCP свои права и рабочая папка команды; настройка Filesystem не ограничивает его доступ к ПК.

Локальные конфиги и ARC-профиль храните в игнорируемых `.runtime/`. Не публикуйте их, `connection.md`, ключи или резервные копии на GitHub.
