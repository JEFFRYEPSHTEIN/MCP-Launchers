# CMD MCP для Windows

MCP-сервер, через который Notion или другой MCP-клиент может выполнять команды CMD, запускать программы, управлять процессами и получать сведения о компьютере. Команды выполняются сразу, без подтверждения со стороны сервера, с правами Windows-пользователя, который запустил сервер. Автоматического повышения до администратора нет.

Владелец Bearer-токена получает доступ к любым командам этой учётной записи, включая изменение и удаление файлов. Ограничения одной папкой, как у Filesystem MCP, здесь нет. Клиент Notion может отдельно запрашивать подтверждение действий в своих настройках инструментов.

## Быстрый запуск

Нужны Windows 10/11, поддерживаемая версия Node.js 20.20 или новее и `cloudflared.exe`. Node.js должен быть доступен через `node.exe` и `npm.cmd`. Для HTTPS установите Cloudflare Tunnel, например через `winget install --id Cloudflare.cloudflared --exact`, либо скачайте официальный [cloudflared](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/).

Это отдельный сервер в подпапке `cmd-mcp`; команда `Start All` в корне репозитория управляет четырьмя другими MCP. Откройте PowerShell в папке `cmd-mcp` и выполните:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\Start-Remote.ps1
```

Если PowerShell открыт в корне клонированного `MCP-Launchers`, сначала выполните `Set-Location .\cmd-mcp`.

При первом запуске скрипт устанавливает зависимости, собирает сервер и создаёт личный токен. Сервер слушает только `127.0.0.1:8765`. Затем Cloudflare выдаёт адрес вида `https://случайное-имя.trycloudflare.com/mcp`. Скопируйте адрес, который действительно напечатал скрипт.

Если Cloudflare не установлен в PATH:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\Start-Remote.ps1 -CloudflaredPath "C:\Tools\cloudflared.exe"
```

Скрипт также ищет `bin\cloudflared.exe` внутри `cmd-mcp`. Бинарные файлы в GitHub не включены. Повторный запуск использует уже работающий сервер и туннель.

Чтобы получить токен в своём окне PowerShell:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\Show-Connection.ps1
```

Можно сразу показать адрес и токен командой `Start-Remote.ps1 -ShowToken`. Токен не попадает в журналы сервера или исходники. При первой настройке каждому пользователю создаётся собственный ключ; не используйте ключ из чужой установки.

## Папка данных, порт и рабочая папка команд

По умолчанию конфигурация и ключ хранятся в `%LOCALAPPDATA%\PcControlMcp`, а сервер слушает порт `8765`. Если нужен отдельный экземпляр или другой каталог, задайте **до запуска**:

```powershell
$env:PC_MCP_DATA_DIR = 'D:\MCP-Data\Cmd'
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\Start-Remote.ps1 -Port 8766
```

`PC_MCP_DATA_DIR` должен быть абсолютным путём. Используйте ту же переменную для `Show-Connection.ps1`, `Stop.ps1` и `Rotate-Token.ps1`; в новом окне PowerShell задайте её снова. Порт передавайте стартовому скрипту; перед сменой порта штатно остановите работающий экземпляр. Для отдельного ключа выберите отдельную папку данных. В одной папке данных скрипты управляют одним экземпляром.

После `npm.cmd ci` и `npm.cmd run build` основной сервер также принимает `node.exe .\dist\main.js serve --port 8766 --data-dir 'D:\MCP-Data\Cmd'`. Для управления через PowerShell-скрипты удобнее использовать `PC_MCP_DATA_DIR`, чтобы они читали тот же каталог.

Рабочая папка команды задаётся аргументом `cwd` у `pc_run_command` или `pc_start_process`, например `D:\Projects\MyGame`. Без `cwd` используется домашняя папка Windows-пользователя. Это начальная папка процесса: клиент по-прежнему может обращаться к любым доступным пользователю путям. `PC_MCP_DATA_DIR` также не ограничивает доступ к файлам.

## Подключение в Notion

1. Откройте настройки MCP-подключений Notion и добавьте пользовательский сервер.
2. Введите HTTPS-адрес с окончанием `/mcp`, который выдал `Start-Remote.ps1`.
3. Выберите авторизацию через HTTP-заголовок. Имя заголовка: `Authorization`. Значение: `Bearer ВАШ_ТОКЕН`, с пробелом между `Bearer` и токеном.
4. Подключите сервер и разрешите нужные инструменты. Если Notion предлагает только OAuth, вернитесь к выбору способа авторизации и выберите заголовки или API key.
5. Попросите Notion вызвать инструмент сервера, например: «Через CMD MCP выполни `whoami`, затем `ver` и покажи результат».

Quick Tunnel выдаёт временный адрес. После остановки и нового запуска туннеля адрес меняется: замените URL в Notion. Пока сервер работает, компьютер должен быть включён и подключён к интернету. Постоянный домен требует отдельно настроенного Cloudflare Tunnel.

## Инструменты

| Инструмент | Что делает |
| --- | --- |
| `pc_run_command` | Выполняет произвольную строку в `cmd.exe`; принимает рабочую папку и время ожидания. Возвращает stdout, stderr, код выхода или ID продолжающейся сессии. |
| `pc_read_session` | Получает состояние и новые данные долгой команды. |
| `pc_list_sessions` | Показывает сессии этого экземпляра сервера. |
| `pc_stop_session` | Останавливает команду и её дочерние процессы. |
| `pc_get_pc_status` | Возвращает сведения о Windows, времени работы и дисках. |
| `pc_list_processes` | Показывает процессы и их идентификаторы. |
| `pc_start_process` | Запускает программу с аргументами. |
| `pc_stop_process` | Останавливает указанный процесс с проверкой времени запуска, чтобы избежать случайной остановки другого процесса с повторно использованным PID. |

Примеры запросов клиенту:

- «Выполни `dir` в папке моего проекта и покажи файлы».
- «Запусти `npm run build` в папке проекта, затем прочитай результат сессии».
- «Покажи свободное место на дисках».
- «Запусти программу по указанному мной пути».

Обычный вызов команды не создаёт интерактивного окна CMD. Для команд с запросом ввода используйте их неинтерактивные параметры: сервер получает командную строку, а не предоставляет терминал с вводом с клавиатуры.

## Остановка и смена токена

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\Stop.ps1
```

Скрипт обращается к локальному защищённому маршруту завершения работы, закрывает принадлежащие серверу активные команды и останавливает только его собственный туннель. Другие MCP-серверы не затрагиваются.

Для нового токена остановите сервер, выполните:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\Rotate-Token.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\Start-Remote.ps1
```

После смены обновите токен и актуальный URL в клиенте. Старый токен больше не подходит.

## Локальный запуск

Если клиент работает на этом же компьютере, HTTPS-туннель не нужен:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\Start-Local.ps1
```

Адрес по умолчанию — `http://127.0.0.1:8765/mcp`. Для другого порта используйте `-Port 8766` в обоих стартовых скриптах; сначала остановите работающий экземпляр.

## Где хранятся данные

Все личные данные запуска лежат вне репозитория, в `%LOCALAPPDATA%\PcControlMcp`:

- `token.json` — личный токен; файл ограничен текущей учётной записью Windows.
- `connection.json` — адрес, порт и идентификаторы собственных процессов сервера/туннеля.
- `server-output.log`, `server-error.log`, `tunnel-output.log`, `tunnel-error.log` — технические журналы запуска. Команды, их аргументы, результаты и токен сервер по умолчанию не записывает.

Не публикуйте `token.json` и содержимое вывода `Show-Connection.ps1`. В GitHub можно отправить исходники и скрипты репозитория; каждому пользователю при запуске создаётся собственный токен.

При заданном `PC_MCP_DATA_DIR` перечисленные файлы находятся в выбранном каталоге. Храните его вне исходников репозитория. Генерируемые `node_modules/`, `dist/`, `bin/` и журналы исключены из Git.

## Проверка исходников

```powershell
npm.cmd ci
npm.cmd test
```

Тесты собирают исходники, запускают временный сервер на свободном локальном порту с отдельным временным ключом, проверяют авторизацию, команды, сессии и штатную остановку. Работающие экземпляры CMD MCP не затрагиваются.

## Если не запускается

Убедитесь, что `node --version` и `npm.cmd --version` работают. Если порт занят, остановите его текущий экземпляр своим скриптом либо выберите свободный порт. При ошибке туннеля проверьте интернет и `tunnel-error.log`. При ошибке сервера проверьте `server-error.log`.

В PowerShell вставляйте только команды внутри блоков, без строк с тройными обратными кавычками. В скриптах путь к папке определяется после чтения параметров, поэтому запуск через `powershell.exe -File` поддерживается Windows PowerShell 5.1.

Сервер отслеживает активные корневые процессы сессий и их деревья при остановке. Программы, намеренно запущенные как отдельные фоновые процессы после завершения команды (например через start), могут продолжать работу; их можно остановить инструментом pc_stop_process. Полный доступ к CMD позволяет клиенту самостоятельно читать любые файлы текущего пользователя, в том числе локальную конфигурацию сервера.
